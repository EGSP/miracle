# Установка пакетов

## Минимальный набор

```bash
npm install @yandex-cloud/nodejs-sdk
```

SDK содержит все сервисы (Compute, IAM, AI, OCR и др.) в одном пакете. Отдельно устанавливать ничего не нужно.

## Требования к окружению

| Требование | Версия |
|-----------|--------|
| Node.js | >= 22.15 |
| TypeScript | >= 5.0 (рекомендуется) |

## Переменные окружения

Проект использует API-ключ и идентификатор папки. Добавьте в `.env`:

```env
YANDEX_CLOUD_API_KEY=AQVN...ваш_ключ
YANDEX_CLOUD_FOLDER_ID=b1g...ваш_folder_id
```

### Где взять значения

- **API-ключ** — Yandex Cloud Console → сервисный аккаунт → «Создать новый ключ» → «API-ключ»
- **Folder ID** — Yandex Cloud Console → облако → папка → вкладка «Обзор»

## Что дополнительно может понадобиться

```bash
# Если нужна работа с файлами (OCR изображений с диска)
npm install fs          # встроен в Node, не требует установки

# Если нужны HTTP-запросы без gRPC (прямой REST)
npm install node-fetch  # или используйте встроенный fetch (Node 18+)
```
