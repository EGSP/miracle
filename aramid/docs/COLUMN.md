# Column

Ячейка сетки внутри `Grid`: ширина и позиция задаются через проп **`span`** (одно «размерное» определение, без `sm` / `md` / `lg`) и при необходимости через объект с полями `start`, `end`, `offset`.

## Когда использовать

- Внутри `Grid` (или вложенного `Grid` с subgrid), когда контент должен занимать фиксированное число колонок или задаваться через линии сетки.
- Не используйте как универсальную обёртку вне сетки — для вертикальных/горизонтальных стеков без колонок смотрите [STACK.md](./STACK.md).

## Импорт

```tsx
import { Column } from '@miracle/aramid';
```

## Примеры

### Простой span

```tsx
<Grid>
  <Column span={12}>Половина сетки (12 из 16)</Column>
  <Column span={4}>Узкая колонка</Column>
</Grid>
```

### Объект: span, offset, start, end

```tsx
<Grid>
  <Column span={{ span: 8, offset: 2 }}>С отступом в колонках</Column>
</Grid>
```

```tsx
<Grid>
  <Column span={{ start: 2, end: 10 }}>Явные линии grid-column</Column>
</Grid>
```

`offset` преобразуется в стартовую линию как `offset + 1` (если не задан `start`).

## Пропсы

| Проп | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| `as` | `React.ElementType` | `'div'` | Корневой элемент. |
| `children` | `React.ReactNode` | — | Контент колонки. |
| `className` | `string` | — | Дополнительный класс рядом с `aramid-column`. |
| `span` | см. ниже | — | Ширина/позиция в колонках. |

### Тип `span`

- **Число** `1…16` — сколько колонок занять.
- **`'25%' \| '50%' \| '75%' \| '100%'`** — доля строки (как в Carbon для части кейсов).
- **`boolean`** — нормализуется в объект с полем `span` (как в типах Carbon).
- **Объект** `{ span?, offset?, start?, end? }` — гибкое позиционирование.

## CSS-переменные

Компонент выставляет в `style`:

- `--col-span`, `--col-start`, `--col-end` — в зависимости от переданного `span`.

Класс `aramid-column` в `aramid-column.css` задаёт:

```css
grid-column: var(--col-start, auto) / var(--col-end, span var(--col-span, var(--aramid-column-span-default)));
```

Дефолтный span привязан к токену `column.span.default` (обычно совпадает с `grid.cols`).

## Лучшие практики

1. **Предпочитайте простой числовой `span`**, пока не нужны `start`/`end`/`offset`.
2. **Не вкладывайте `Column` вне `Grid`** — поведение `grid-column` зависит от родительской сетки.
3. **Согласуйте сумму span-ов** с числом колонок (16), чтобы не получать неявные переносы без намерения.
4. **Кастомный `style`** можно использовать для точечных переопределений переменных; не дублируйте полную раскладку в своём CSS без нужды.

## Доступность

- Колонка не добавляет роли: при необходимости задайте `role` / заголовки на уровне секции или используйте семантический `as`.
