# Stack

Утилита раскладки **flex** с управлением расстоянием между дочерними элементами через **`gap`** (как идея Carbon Stack: отступы между элементами задаёт родитель, а не margin у каждого ребёнка).

## Когда использовать

- Вертикальный или горизонтальный список блоков, кнопок, полей формы с равномерным интервалом.
- Когда не нужна колоночная сетка — для сетки см. [GRID.md](./GRID.md).

## Импорт

```tsx
import { Stack } from '@miracle/aramid';
```

## Примеры

### Вертикальный стек (по умолчанию)

```tsx
<Stack gap={5}>
  <div>Первый блок</div>
  <div>Второй блок</div>
</Stack>
```

Число `gap` — шаг шкалы spacing: в `style` подставляется `var(--aramid-spacing-N)`.

### Горизонтальный стек

```tsx
<Stack orientation="horizontal" gap="12px">
  <button type="button">Назад</button>
  <button type="button">Далее</button>
</Stack>
```

Строковый `gap` — любое валидное CSS-значение для `gap`.

## Пропсы

| Проп | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| `as` | `React.ElementType` и др. | `'div'` | Корневой элемент. |
| `children` | `React.ReactNode` | — | Дочерние узлы между которыми задаётся `gap`. |
| `className` | `string` | — | Дополнительный класс рядом с `aramid-stack`. |
| `gap` | `1…13 \| string` | — | Межэлементный интервал. Число → токен `--aramid-spacing-*`; строка → как есть. |
| `orientation` | `'vertical' \| 'horizontal'` | `'vertical'` | Направление flex. |

Поддерживаются стандартные HTML-атрибуты родителя (`role`, `aria-*`, `data-*`, `style` и т.д.).

## CSS-переменные

Класс `aramid-stack` использует:

- `--stack-direction` — `row` или `column` (выставляется из `orientation`).
- `--stack-gap` — явное значение или `var(--aramid-spacing-N)` для числового шага.

См. `src/components/Stack/aramid-stack.css`.

## Лучшие практики

1. **Не задавайте внешние вертикальные margin детям** для «межстрочия» — используйте `gap` у `Stack` (или несколько `Stack` с разными `gap`).
2. **Числовой `gap`** держит визуальный ритм в линии токенов spacing; произвольные строки — только когда макет требует вне шкалы.
3. **Группировка действий** в формах и тулбарах — типичный кейс для `orientation="horizontal"` и умеренного `gap`.
4. **Вложенные `Stack`** допустимы: внешний задаёт крупный шаг, внутренний — мелкий.

## Доступность

- Для группы кнопок в одном ряду предпочтительна семантика `role="group"` и видимая подпись (`aria-label`), если нет текстового заголовка рядом.
