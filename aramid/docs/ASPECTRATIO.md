# AspectRatio

Контейнер с фиксированным **соотношением сторон** для медиа и других блоков, чтобы макет не «прыгал» при загрузке контента. Реализовано через CSS **`aspect-ratio`** и переменную `--aspect-ratio`.

## Когда использовать

- Изображения, видео, превью, карты с placeholder.
- Когда важно зарезервировать место под контент до появления реальных размеров.

## Импорт

```tsx
import { AspectRatio } from '@miracle/aramid';
```

## Примеры

### 16:9 для видео

```tsx
<AspectRatio ratio="16x9">
  <video controls src="..." style={{ width: '100%', height: '100%', objectFit: 'cover' }} />
</AspectRatio>
```

### 1:1 для карточки

```tsx
<AspectRatio ratio="1x1" as="figure">
  <img alt="" src="..." style={{ width: '100%', height: '100%', objectFit: 'cover' }} />
</AspectRatio>
```

## Пропсы

| Проп | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| `as` | `React.ElementType` | `'div'` | Корневой элемент (полиморфный). |
| `children` | `React.ReactNode` | — | Контент внутри области с заданным соотношением. |
| `className` | `string` | — | Дополнительный класс рядом с `aramid-aspect-ratio`. |
| `ratio` | см. ниже | `'1x1'` | Соотношение сторон. |

### Значения `ratio`

`1x1`, `2x3`, `3x2`, `3x4`, `4x3`, `1x2`, `2x1`, `9x16`, `16x9`.

Внутри значение преобразуется в CSS `width / height` для `aspect-ratio`.

## CSS

Класс `aramid-aspect-ratio` задаёт `width: 100%` и `aspect-ratio: var(--aspect-ratio, 1 / 1)`. Переменная `--aspect-ratio` выставляется из пропа `ratio`.

## Лучшие практики

1. **Медиа на всю область** — дочернему элементу задавайте `width: 100%`, `height: 100%` и `object-fit` (для `<img>` / `<video>`), иначе соотношение будет у контейнера, а контент может не заполнять его.
2. **Не растягивайте интерактив поверх медиа** без явного слоя: для оверлеев используйте отдельный позиционированный слой с доступностью (фокус, кликабельная область).
3. **Семантика** — для иллюстраций используйте `as="figure"` и связку с `<figcaption>` при необходимости.

## Доступность

- Для декоративных изображений используйте пустой `alt=""`; для содержательных — осмысленный `alt`.
- Видео и аудио снабжайте субтитрами/расшифровкой по требованиям продукта.
