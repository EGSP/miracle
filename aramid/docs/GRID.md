# Grid

Корневой контейнер **CSS Grid** для раскладки страницы и секций. Один десктопный режим (без пропсов `sm` / `md` / `lg`): число колонок и отступы задаются токенами и переменными `--grid-*`. Вложенные `Grid` автоматически становятся **subgrid** относительно родителя (как в Carbon 2x Grid).

## Когда использовать

- Нужна предсказуемая колоночная сетка (по умолчанию 16 колонок).
- Нужна вложенная сетка с выравниванием по линиям родителя (`subgrid`).
- Не смешивайте с «ручными» `display: grid` на том же уровне без понимания линий сетки.

## Подключение

В корне приложения один раз:

- `@miracle/aramid/css/tokens` — переменные `--aramid-*`
- `@miracle/aramid/styles` — классы `aramid-grid`, `aramid-subgrid` и остальные стили пакета

См. [README.md](../README.md).

## Импорт

```tsx
import { Grid, Column } from '@miracle/aramid';
```

## Базовый пример

```tsx
<Grid>
  <Column span={8}>Основной контент</Column>
  <Column span={8}>Боковая колонка</Column>
</Grid>
```

## Вложенный Grid (subgrid)

Внутри первого `Grid` каждый следующий `Grid` рендерится с классом `aramid-subgrid` и наследует колоночную структуру родителя. Дополнительно настраивайте только пропы зазора/режима при необходимости.

```tsx
<Grid withRowGap>
  <Column span={16}>
    <Grid condensed>
      <Column span={8}>A</Column>
      <Column span={8}>B</Column>
    </Grid>
  </Column>
</Grid>
```

## Пропсы

| Проп | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| `as` | `React.ElementType` | `'div'` | Корневой элемент (полиморфный корень). |
| `children` | `React.ReactNode` | — | Содержимое сетки. |
| `className` | `string` | — | Дополнительный класс рядом с `aramid-grid` / `aramid-subgrid`. |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | Горизонтальное положение блока сетки в потоке (`margin-inline-*`). |
| `condensed` | `boolean` | `false` | Узкий межколоночный зазор (токен `--aramid-grid-gutter-condensed`). |
| `narrow` | `boolean` | `false` | Без горизонтальных отступов контейнера (`padding-inline: 0`). Имеет приоритет над `condensed` при определении режима. |
| `fullWidth` | `boolean` | `false` | `max-width: 100%` вместо ограничения по токену. |
| `withRowGap` | `boolean` | — | Если задано, межстрочный зазор совпадает с текущим межколоночным; если не передано — строки без дополнительного вертикального зазора. |

Остальные атрибуты HTML (в т.ч. `style`, `role`, `aria-*`) пробрасываются на корневой элемент.

## CSS-переменные

Компонент выставляет в `style` (корневая сетка):

- `--grid-cols` — число колонок (сейчас `16`, в духе токена `grid.cols`).
- `--grid-column-gap`, `--grid-row-gap`, `--grid-padding-inline`, `--grid-max-width`
- `--grid-margin-inline-start`, `--grid-margin-inline-end` — из `align`

Для вложенной сетки дополнительно:

- `--subgrid-column-gap`, `--subgrid-row-gap`

В CSS классы читают сначала `--grid-*`, затем fallback на `--aramid-*` из `tokens.css` (см. `src/components/Grid/aramid-grid.css`).

## Лучшие практики (как в Carbon)

1. **Один корневой `Grid` на страницу или секцию** — избегайте лишней вложенности без смысла.
2. **Колонки — через `Column`**, а не произвольные `div` с `grid-column`, если хотите единообразие с токенами и пропом `span`.
3. **`narrow` и `condensed`** — осознанно: narrow убирает поля контейнера, condensed сжимает зазор между колонками; не включайте оба «на всякий случай».
4. **`withRowGap`** — включайте, когда вертикальный ритм между строками должен совпадать с горизонтальным «желобом».
5. **Переопределение через `style`** — допустимо для точечных кейсов; не дублируйте всю сетку в кастомном CSS без необходимости.

## Доступность

- Сам по себе `Grid` не задаёт семантику: при необходимости используйте `as="section"` и заголовки секций (`aria-labelledby` / структура заголовков).
- Не делайте сетку единственным способом передачи смысла порядка контента: порядок в DOM должен совпадать с логическим чтением.
