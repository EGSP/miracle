Используй папки по назначению

Desk - промежуточные файлы при работе с субагентами, куда можно складывать информацию необходимую для выполнения текущей задачи:
Например, отчеты и исследования кодовой базы (чтобы каждый агент не читал), паттерны работы. Стол можно очищать при реализации нового плана.

Каждое исследование — **отдельная подпапка** `.agents/desk/<краткое-имя>/`:
`report.md`, `patterns.md`, `manifest.json` (+ детальные файлы по необходимости).
Пример: `.agents/desk/document-prepare/` — паттерны DPS для implementer.

Lectures - лекции для пользователя.

Plans - планы по реализации. Если палн берется в работу, то нужно вести рядом dp.report.md.
