Название miracle
Описание Обработка опросных листов ИИ агентом

Монорепозиторий - фронт, бек и tools (всё на typescript)

Бек: 
- Node, Express, Lowdb

Фронт:
- React, Vite, Tanstack(query, router), zustand, lucide-icons, shadcn

Установи все пакеты используя тег latest при запуске команды npm install packagename@latest

Монорепо добавь команды: 
- install:all (запускает инсталл для всех пакетов)
- launch:full
- launch:back
- launch:front

Добавь .env файл в корень проекта. В нём будут данные для бека и фронта. Запуск бека и фронта сделай с передачей .env (возможно нужен dotenv).

Добавь запуск проекта по кнопке F5 (vscode). Сделай запуск Full с запуском бека и фронта + браузер и всё с отладкой. Если закрывается бек или фронт - сделай закрытие всех процессов.
